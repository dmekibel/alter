## E · deviations, named
1. **Raise → cutout.** The frame raises the lit element above a flat scrim; ALTER's targets sit inside `#trackerFull`
   (`position:fixed; z-index:90`), a stacking context, so a raise is impossible. A cutout at the target's live rect
   replaces it. Measured cost: the app's home ground under the scrim differs from the undimmed pixel by ≤ ~7/255 per
   channel, so the background reads the same; the lit element itself is identical either way. Cost that remains: the
   negative space INSIDE a lit container (the gaps between the four shortcut tiles, say) is undimmed here where the
   frame leaves it dim.
2. **TOOLS ring sits 10px lower than the frame's.** The frame anchors that pill with `bottom:21px` on an 874 artboard,
   which lands it 8.5px above its own cue's centre; the port centres it on the cue so it reads correctly at any
   height. Size (86x50), stroke, radius and keyframes are the frame's exactly.
3. **Beat 6 lights one thing, the frame lights two.** The frame keeps the top HOME threshold lit alongside the
   bottom-left home button. One scrim can carry one cutout — two stacked scrims would darken the rest of the board
   to .86 — so the port lights the button the copy actually names ("tap the home button") and leaves the threshold dim.
4. **No arrow on the settings beat.** The panel caption says "one short arrow beside it"; neither the playable frame
   nor the static P6a frame draws one (`tourArrowNudge` is declared and used zero times in the bundle). The bubble's
   top tail landing on the icon IS that arrow. FRAME WINS; nothing invented.
5. **Skip reads "Skip".** The rejected build said "I'll find my way"; both P1 frames draw `Skip`, in the corner of the
   line itself. RU `Пропустить` was already in the dictionary.
6. **Screenshots are not persisted as PNGs.** The pane's screenshot tool returns images to the session, not to a path,
   and this Mac has no headless capture (no puppeteer, no chrome --screenshot driving the beat state). Every beat was
   screenshotted and diffed visually in-session; the machine numbers above are the durable record.
