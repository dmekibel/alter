# GOALS EMBODIMENT — candidate pool (2026-08-10, pre-skeptic)

Question: what does a GOAL look like on the island? David's seed: functional builds (boat you then sail, skateboard you then ride). Goal = real-life goal with sub-goals; each sub-goal completed advances the build by a stage; the finished thing is USABLE, not just decorative. Tiers already locked: quests = ledger only, ventures = functional perks, sagas = rare wonders.

Format: name: what you build (stages) → what it DOES once built.

## VESSELS & TRAVERSAL
1. Rowboat (David's, canon): hull → oars → lantern rig → sail the near water, see your island from the sea.
2. Skateboard (David's): deck → trucks → paint → ride the paths, fast travel between zones.
3. Sailboat: the rowboat's saga tier; mast + sail → catch wind, dusk sails.
4. Moon-pool raft: lashed logs + pole → punt across the pool.
5. Diving bell: brass dome + winch → see under the island's water, sunken details nobody else gets.
6. Kite: frame + silk + string → fly it in weather from the peak.
7. Glider: wings + harness → launch from the summit, one slow circle over everything you've built.
8. Bicycle: frame + bell + basket → ride the ring path.
9. Sled: runners + rope → slide the slope in a winter era.
10. Zipline: anchor + cable + handle → peak to shore in one whoosh.
11. Funicular: track + car → shore to summit, slow scenic ride.
12. Horse + stable: the stable is the build; the horse arrives at completion → a companion you ride.
13. Turtle ferry: build the old turtle a feeding dock → she carries you across the shallows.
