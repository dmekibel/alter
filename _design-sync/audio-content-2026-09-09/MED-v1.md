**How long a sit now stays guided.** At the `often` cadence a 10-minute Concentration sit spends about 26 cues on the breath spine, so its 28 lines cover it with no repeat; a 20-minute sit at `some` or `spacious` spends 24 and 14. The other spines land the same way (note 20, open 20, embody 20, heart 16, being 16). A 20-minute sit at `often` still outruns the longest pool, and when that happens the engine **wraps the pool from the top** (`blk.pool[pi++ % blk.pool.length]`), it does not fall through to MED_RETURN. The brief describes that fallback the other way round, so this is the one engine fact to build against.

## 2. The tier structure (every pool is a ladder, authored order = the order it speaks)

**foundation** (first third: a first-timer can do it) → **working** (the technique proper, plus its named correction) → **subtle** (needs the working tier to be easy first) → **effortless** (drops the effort and tests whether the skill holds on its own). Existing lines stayed in their relative order and the new lines were interleaved so the whole pool reads as one ladder, which means the deeper rungs are only reached by a longer sit. Each block carries a `//` comment naming its ladder.

Three corrections are the highest-value additions in the set, and each is where the sweep said it would be:
- **breath, the subtle-dullness pair.** Calm-and-foggy reads as depth and is the best-disguised failure in the whole ladder, so it gets a detect line and a fix line back to back (TMI stage 5).
- **feel, the exit.** Turn-away and stopping are written into the pool as complete practices, never as giving up (trauma-sensitive rule, sweep section E2).
- **look, the off-ramp.** The orientation line is `pool[0]` and the stop-and-return-to-the-breath line is `pool[2]`, so a gated sit hears both before any deep prompt.

## 5. The copyright pivot, held

Technique is free, expression is owned. Every line is the generic move rendered in plain words the whole tradition shares. No sentence tracks a living teacher's phrasing, and the technique LABELS the sweep uses to think precisely (Just Note Gone, Do Nothing, See Hear Feel, the three meters) appear nowhere in the copy. The one place a name surfaces is a lane's tradition tag, which the app already ships (`· TMI`, `· Shinzen`). See judgment call 3 below for how Headspace was handled.

## 6. Judgment calls, one line each, all reversible

1. **`joy` folded into the Concentration lane at weight 0.6.** The sweep's EVIDENCE: TMI puts joy (stages 8 to 9) directly after the breath ladder's stage 7, so it reads as a deeper rung of that lane. Delete the one pair if you want Concentration pure.
2. **The four orphan blocks got homes inside existing lanes, one each:** `listen` into Open awareness, `watch` into Insight, `feel` into Mindfulness, `scan` into the new Body lane. The brief defines Reset as settle/count/free/close, so a Senses lane would have exceeded the named lane list; "a lane may gain one block" was the lever instead. Every lane now gains exactly one block except Heart.
3. **Lane tags: Reset carries no teacher tag.** Body is tagged `· Blackstone` and Being `· Adyashanti`, matching the shipped `· TMI` / `· Shinzen` pattern, but Headspace is a competitor's brand and naming it in-product is a trademark and endorsement problem, which is the same reason the copyright pivot exists.
4. **The one line that reaches past plain physical sensation** is embody's "Some days there is a faint sense of movement through the middle of you. Take it if it's there today." It is Blackstone's core move, hedged twice. Cut it and the line after it if you want the block strictly physical.
5. **`sleep` and `joy` are deliberately NOT in MED_SEC** (the stack editor's section bank). Sleep has no return by design and must never be pickable into a daytime stack; joy lives behind the Concentration lane. One line each adds them if you want them.
6. **Never add `free`, `sleep`, or `being` to the engine's RETURN weave list.** A "come back to the breath" cue detonates free's whole premise, and sleep's rule is that it never returns at all.
7. **RU is not authored here.** The new section names (Embody, Free, Being, Sleep, Joy) and lane names (Body, Reset) have no RU key yet, so the player prints the EN name until a dict pass adds them.

## 7. What in the sweep I judged unusable, and why

- **MCTB stages 4 to 10 (the Dark Night cluster).** Excluded as technique, per the sweep's own binding gate. `look` stops at thought-as-thought and no-self-found, which is where its existing lines already stopped.
- **The self-scoring moves** (breath 18 "notice the longest unbroken stretch", note 16 "which of the three qualities is weakest"). Dropped: mid-sit self-measurement is a report, not an instruction, and it walks into the VOICE-BIBLE ban on trend and metric vocabulary in the guardian's mouth.
- **The hypnotic descend image in `settle`** (stairs, elevator, HYP §3). Dropped there: its own source requires asking first whether the image carries a bad association, which no single spoken line can do. The technique survives where the pre-sleep source actually wants it, as sleep's float-or-sink line.
- **`co2-bohr-effect`'s 6:8 ratio and the BOLT self-test.** The sweep already ruled these belong to the separate breathing tool. Not used.
- **The duplicated Adyashanti bait line** (it appears in the ladders for watch, open, being, and look). Written four times would have shipped four near-identical clips into two shared lanes, so each block got a mechanically different version and `look` took a different Adyashanti move instead.
- **The sweep's `rest` block name.** Resolved to `being` per the brief: `MED_SEC.rest` is a legacy alias for `open` and saved user tracks resolve through it.

`being` needs its `adv` flag to reach the editor, and `medView` currently drops it. One word fixes it for every future block:

```js
  function medView(bk, extraLines) { var b = MED_BLOCKS[bk] || {}; var ls = [b.entry].concat(b.pool || []); if (extraLines && extraLines.length) ls = ls.concat(extraLines); return { name: b.name, col: b.c, ti: b.ti, adv: b.adv, lines: ls }; }
```

(Zero-touch alternative, if `medView` stays as it is: `being: Object.assign(medView("being"), { adv: true }),`)
