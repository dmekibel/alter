## 1. THE DIAGNOSIS (why the current journey is broken)
It's a **curriculum wearing a game costume**: text lessons chained by arrows. So it reads like homework (walls of text), stalls (a lesson you don't feel like reading is a wall), and looks like a worksheet (arrows, boring nodes). The game layer is decoration on top of reading. Decoration on reading is always ugly, because reading isn't play.

## 2. THE LAW (the one consolidating move)
> **WISDOM IS NEVER DELIVERED AS TEXT. WISDOM IS DELIVERED AS A REP.**
> Each journey node = one interactive ritual (Ritual Engine) that *embodies* the lesson. The teaching enters through the body and one spoken line, not through paragraphs.

**The de-text formula.** Every Johnson lesson (and any grimoire content) compresses into exactly three layers:
1. **THE LINE** — one aphorism, VOICE-BIBLE "LAW" form, ≤10 words, spoken by the guardian at the peak of the rep. ("What's wrong is always available. So is what's right.")
2. **THE REP** — a 1–3 minute interactive ritual that *is* the lesson. Targeted Thinking isn't explained; you *do* the swap live on a real thought. The lesson about energy isn't read; you do the breath and *feel* it.
3. **THE WHY** — one tap deep, optional, for the David-types. Mechanism, source thinker, science. Never on the main path. (Appetite-dosed: the girlfriend never sees it, the seeker opens it every time.)

The 300-day course survives **as the invisible syllabus**: the Sequencer (already mined, 82 beads, `engine-v1.json`) orders which rep arrives on which day, adapted by the psychograph and the energy read. The user never sees a curriculum. They experience: *my guardian hands me one thing each day, and it's always strangely right.*

## 3. THE CONSOLIDATED ARCHITECTURE (four systems become one loop)
- **ONBOARDING** = journey day 1 (already decided). The 4-beat front door, then the first session. Nothing separate.
- **JOURNEY** = the chain of daily **sessions** (not lessons). One session/day = arrive (energy read routes it) → 1–3 reps (prescriptive default, subtract if you want) → seal (charge lands, one line, envelope). All inside the **cockpit stage** (which transforms into the tools player — decided).
- **TOOLBOX** = not a menu you browse but **the collection the journey leaves behind**. Every rep charges that tool's sigil; installed sigils sit in the constellation; from there any tool can be re-run anytime (the timeless-tools layer). The toolbox is the *residue of the journey* — that's why it's never overwhelming: it grows one tool at a time, at the pace you actually learned them.
- **THE GAME** = not a fourth thing. The game is the loop itself: reps charge sigils → sigils build stacks → stacks advance the arc → the world (timeline past + constellation) visibly grows more beautiful. June's Journey investment, pointed at a real life.

**One sentence:** *the journey teaches by making you perform; the toolbox is what the performing leaves installed; the game is watching yourself accumulate; onboarding is just day one of it.*

## 5. WHY IT CAN'T STALL ANYMORE
The old journey stuck because a text lesson can refuse to be read. A rep can't stall the same way, because:
- The energy door routes it: low arrival gets the 60-second relief rep; there is **always a floor-dose version** of the day's node (Mom's 2-tap ceiling law).
- Prescriptive-subtractive: the session is pre-assembled; you subtract, never compose.
- If you skip N days, the journey doesn't pile up homework — the Return rite IS the next node (drift-recovery as content, v910's Relight made canon).
