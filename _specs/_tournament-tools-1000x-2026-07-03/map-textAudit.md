## 2. AUDIT

### FLAT (generic self-help sludge any app could say)

**Onboarding:**
- "your guardian. I'll help you become who you want to be — one day at a time." — could be Headspace, Noom, or a Hallmark card. The promise is maximally vague. Every self-help app says this exact thing.
- "Running on empty" / "Getting by" / "Good energy" — three battery labels that are exactly what every mood-tracker uses. No voice, no specificity.

**Journey nodes:**
- "Name what you actually want. One sentence — your real reason." — workbook filler.
- "Open the day on purpose. Close it with one honest line. Repeat." — this is a paraphrase of every morning-pages product description since 2012.
- "Energy, work, love — map today across all three." — a plain content-list, not a line with a point of view.

**Stack builder:**
- "grab a ready pack by the time you have — or build your own on the timeline." — UX copy, reads like an onboarding tooltip, no voice at all.
- "your session · take your time" — lifeless. What is it saying that 'your session' doesn't already say?
- "Session complete" + "N tools · carry the calm with you" — 'carry the calm with you' is now the default ending line of 80% of mindfulness apps (Calm, Headspace, Insight Timer all use this exact phrase).

**Tool WHY lines:**
- "Watching thoughts without grabbing them quiets the mind's default chatter — focus returns." — mechanically correct, clinician voice, zero pulse.
- "A repeated phrase in a calm state seeds the subconscious — repetition is how self-image installs." — Wikipedia prose.
- "Gratitude shifts you out of the threat network into the care network — a different brain state, on demand." — neuroscience-speak that sounds like a wellness newsletter.

**Pools:**
- Pool 7: "Every day, in every way, I'm getting better and better." — this is the single most famous cliché in the entire self-help canon (Coué, 1920). It will hit the user as parody if they know it. **SPOKEN — expensive to change.**
- Pool 7: "I have everything I need within me, now." — generic completion fantasy. **SPOKEN.**
- Pool 12: "Where attention goes, the day follows." — repackaged Tony Robbins bumper sticker. **SPOKEN.**
- Pool 9: "What's one thing today taught you — even something tiny?" — textbook. **SPOKEN.**

**Virtue declarations:**
- "I appreciate all the blessings and gifts in my life." — church-bulletin vocabulary; the word 'blessings' is a sludge trigger.
- "I have inspiring goals, agency, and pathways." — PERMA framework recited, not voiced. Reads as if a researcher wrote it.

### CHEESY (violates de-cheese law — mysticism framing, hype, hollow positivity)

**Onboarding:**
- "what I'm about to show you gives you real powers. this is no joke." — this is hype-speech, the register of an ad, not a guardian. The de-cheese law says: structure, not mysticism. This is the opposite.

### INCONSISTENT (voice wobbles)

- **Register gap between onboarding and tools.** The onboarding uses casual lowercase commands ("pick two things up off the floor") while tool cards use clinician language ("lowers amygdala arousal"). These feel like two different writers. The tool WHY lines should match the 'I've been watching you' register of the best onboarding copy.

- **'guardian' never speaks in first person inside the tool flows.** The Sage voice ('your guardian') disappears entirely once a tool starts. Tool beats are written as pure instruction, not as Sage narrating. The onboarding says "I'll wait" — but the relax-muscles steps say "Drop your shoulders, let them fall" with no 'I.' The relax sequence and pool ARRIVE lines are consistent with each other (pure instruction), but inconsistent with the guardian persona established at open.

- **Breathwork finish lines are inconsistent per route.** Tool close: "carry the calm with you." Stack close: "carry the calm with you." Ritual close: toast "done — showing up IS the practice." Pattern-mirror angel: "you labeled it — that's the whole skill." These are four different messages about what completing a session means, and they happen in the same app on the same day.

- **Pool 7 INSTALL mixes tenses and voices.** "Every day, in every way, I'm getting better and better" (third-person self-talk cliché) vs "Today, I create a good day" (present intention) vs "I'm getting steadier — and I can feel it" (present observation). Three different grammatical contracts in six lines. A spoken round needs a single grammatical mode.

- **Journal prompts vs pool REFLECT questions are duplicating without coordination.** "What could you feel proud of today — if you let yourself?" (Pool 9, SPOKEN) and "Something went right today — what was it, even a small thing?" (pm-kept journal prompt, SCREEN) cover the same territory in the same session. They will feel redundant to a user who does both PM ritual and PM journal.

## 3. THE MISSED DEVICES

**Where user data is available but copy speaks in generics:**

1. **Tool WHY lines never use the gauge delta.** After a 0-10 pre/post gauge run, the app knows the user went from 7 to 4. The toast says "3 points lighter — noted" correctly, but the next time they open the same tool, the WHY line still reads "Long exhales pull the vagal brake." It could say: "Last time this took you from [pre] to [post]. That's the data."

2. **Onboarding battery question ignores everything previously entered.** "Running on empty / Getting by / Good energy" — three labels that could reference the user's own habits or goals once the profile pass is done. Instead they are the same three chips for every user always.

3. **Adaptive journal prompts use {int} and {lagv} interpolation (the only two live-data hooks)** but the rest of the prompt bank treats every user identically. A user with 14 days of logged data and a known pattern could get "A quiet day. What's one thing you'd like tomorrow to hold?" — the zero-data fallback — just because the condition logic doesn't match. The pattern-mirror generates data (slip timing, mood-domain correlation) but it surfaces only once per day via `pickPattern()`, never as a journal prompt hook.

4. **Stack step card: "Step N of N · your session · take your time"** — knows the tool name, the user's total chosen session length, and their gauge pre-score. None of these are used. Could be: "Step N of N · you're at [pre]/10 — let this land."

5. **Return-after-gap: "It's been [N] days."** This is the ONE place an actual number is used in the guardian's voice, and it works. The same logic should propagate to: daily open ("You've shown up 3 days this week"), streak chip ("7 in a row — that's the longest you've been"), goal progress nodes ("Toward [goal] · [X]% there").

6. **Pool INSTALL lines are fixed.** "Today, I create a good day" is spoken the same way for a user who is 0 for 7 on their plans AND for a user on a 21-day streak. The line doesn't know who it's speaking to. The recording contract makes this expensive to change, but the **SCREEN** install beat in the Rewire tool ("Say it as now — one present-tense line, like 'I start before I feel ready'") could surface the user's own previously-stated intention from `S.bk[k].am.identity` — giving them their OWN line, not a default. This is SCREEN-ONLY and free to implement.

7. **Brain Gym end-states ("Good run" / "Nice work") never reference the personal best.** The data is in scope (`best`). "Good run · your best is [N]" is one word change and makes the line personal.

8. **The Grateful Flow tool** shows saved gratitudes from `S.profile.gratList` — this IS user data being used. But the opening instruction ("name a few specific things. small is good.") ignores that the app knows their recurring list. After 3 sessions it could say: "You keep coming back to '[most common]' — is that still the one?"
